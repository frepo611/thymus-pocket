# Utvecklardagbok - 2026-05-27

## Genombrott: SMF Forum Authentication och Data Fetching

### Problem

PoC-applikationen kunde inte autentisera sig mot verklig forum (https://www.thymus.se/forum running SMF 2.0.19) trots korrekta inloggningsuppgifter. Forumet returnerade login-formulär även efter HTTP 200-respons från login2-endpoint. Forum-data var inte åtkomlig.

### Root Cause Analysis

**Initialt misstag:** Antog att SMF 2.0.19 kräver SHA1-hashing av lösenord (baserat på HTML-form med `onsubmit="hashLoginPassword(this, sessionId)"` JavaScript-funktion).

**Faktum:** Forumet accepterar **plaintext-lösenord** via HTTP POST. JavaScript-hashing är endast för webbläsare-UI.

### Lösning

#### 1. Authentication

- Tog bort SHA1-hashing-logik
- Skicka plaintext-lösenord i `passwrd`-fältet
- Inkludera alla dynamiska hidden fields från login-form (för CSRF-skydd)
- Session-persistence: PHPSESSID + SMFCookie928 cookies sparas till JSON

**Resultat:** Login successful ✅

#### 2. Board & Topic Parsing

**Problem:** CSS-selector `a.subject[href*='board=']` returnerade 0 results.

**Orsak:** Board-länkar har INTE klassen "subject". HTML-struktur var:

```html
<a href="...?board=6.0">thymusattityd</a>
```

**Lösning:** Ändra selector till `a[href*='board=']` och filtrera bort `action=unread` liens:

```csharp
document.QuerySelectorAll("a[href*='board=']")
    .Where(href => !href.Contains("action=unread", StringComparison.OrdinalIgnoreCase))
```

**Resultat:** Hittar nu alla 10 boards ✅

#### 3. Forum Data Extraction

- Hämtar första sidan per board (optimering implementerad tidigare)
- **Total data:** 268 topics från 10 boards
- Board: thymusattityd, Sittningar, Sånger, Rollspel, etc.

| **Cookie Persistence** | CookieContainer + JSON-serialisering låter session återanvändas mellan körningar |
